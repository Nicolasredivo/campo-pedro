# Campo do Pedro

Aplicativo para montar a escalação: cadastre os jogadores dos dois times e posicione cada um livremente no campo, com placar, cronômetro, reservas, substituições e histórico dos jogos.

**Abrir o aplicativo:** https://nicolasredivo.github.io/campo-pedro/

- No Android (Chrome), toque em **Instalar** quando o aviso aparecer: o ícone vai para a tela inicial e o app funciona sem internet.
- No iPhone (Safari), toque em **Compartilhar** → **Adicionar à Tela de Início**.

Os times e jogadores ficam guardados no próprio celular de cada pessoa. Para passar tudo de um celular para outro, use **Menu → Cópia de segurança**.
